# TimeApp — контроль времени за ПК через Telegram

Приложение для Windows 10/11: считает, сколько ты сегодня провёл за компьютером, показывает
статистику в Telegram-боте **@cntrlpctime_bot**, и умеет ограничивать время —
дневной лимит и циклы «работа/перерыв» с блокировкой мыши и клавиатуры.
Управлять могут назначенные админы прямо из бота.

## Как это работает

1. Запускаешь `TimeApp.exe` — открывается окно с **6-значным кодом** (код действует **30 дней**, потом сам меняется).
2. Открываешь бота в Telegram (кнопка в окне) и отправляешь ему этот код.
3. Бот показывает статистику (**Сьогодні / Today**, **Тиждень / Week**) и, если ты админ, кнопки управления.

Язык переключается и в боте (кнопка «🌐 Мова / Language»), и в окне (флажки сверху): **английский / украинский**.
**Автозапуск с Windows включён всегда** — приложение прописывает себя в автозагрузку при каждом старте.

## Админы и управление

В окне → кнопка **⚙ / Керування** открывает настройки. Там:

- **Админы** — впиши `@username` из Telegram. Админов можно добавить **сколько угодно**.
  Как только админ напишет боту, бот узнаёт его по нику и даёт кнопки управления.
- **Дневной лимит** (минуты) — сколько всего можно за день.
- **Работа / Перерыв** (минуты) — цикл: например работа 30 → перерыв 30. Во время перерыва
  **мышь и клавиатура блокируются**, на весь экран выводится окно с обратным отсчётом.
- **Токен бота** — для второго ПК (см. ниже).

Команды админа в боте (или те же действия кнопками):

| Команда | Что делает |
|---|---|
| `/setlimit 120` | дневной лимит 120 мин (0 — выключить) |
| `/setcycle 30 30` | цикл: 30 мин работы / 30 мин перерыва (0 0 — выключить) |
| `/addtime 15` | добавить 15 мин к лимиту на сегодня |
| `/breaknow 10` | перерыв прямо сейчас на 10 мин |
| `/unlock` | снять текущую блокировку |
| `/resetday`, `/resetweek` | **сбросить** насчитанное время за день / за неделю |
| `/apps` | **топ программ** за сегодня — в чём именно сидел |
| `/block youtube.com/shorts` | **заблокировать сайт** (можно с путём после домена) |
| `/unblock …`, `/blocklist` | убрать из списка / показать список |
| `/setpin 1234`, `/clearpin` | **PIN-защита** приложения (настройки + выход) |
| `/setbotpin 1234`, `/clearbotpin` | **PIN входа в бота** для админов (см. ниже) |
| `/update`, `/version` | проверить/поставить обновление, показать версию |
| `/uninstall` | **удалить** TimeApp с ПК (подтверждение + PIN) |
| `/status` | текущие настройки и состояние |

Когда наступает перерыв или достигнут лимит, все админы получают уведомление в боте.

## PIN входа в бота (для админов)

Обычно админ узнаётся по `@username`. Если хочешь второй фактор — поставь **PIN входа в бота**:

- Задай его в ⚙ Настройках или командой `/setbotpin 1234`.
- После этого любой админ (тот, чей `@username` вписан в настройках ПК), заходя в бота, должен
  сначала **прислати боту этот PIN** — тогда откроется управление. Ты сам, будучи админом, тоже
  вводишь PIN при входе.
- Смена PIN (`/setbotpin`) выкидывает все прошлые входы — нужно ввести новый. `/clearbotpin`
  возвращает вход только по `@username`.

## Защита, предупреждения, блокировка сайтов

- **PIN-защита.** Поставь PIN (в ⚙ Настройках или командой `/setpin 1234`) — после этого
  **открыть настройки** и **выйти из программы** можно только по PIN. Контролируемый не сможет
  удалить админов, подменить токен или закрыть приложение.
- **Предупреждение перед блокировкой.** За N минут (по умолчанию 5, настраивается) до перерыва
  или дневного лимита выскакивает уведомление «Осталось: …», чтобы блок не был внезапным.
  `0` — выключить.
- **Статистика по программам.** Считается, в каких программах проведено время. Смотреть — кнопка
  «🗂 Программы» или `/apps`.
- **Блокировка сайтов, в том числе по пути.** `youtube.com` блокирует весь сайт, а
  `youtube.com/shorts` — **только шортсы**, обычные видео при этом работают. Поддомены
  (`m.youtube.com`) тоже попадают под правило. Когда открыт заблокированный адрес, вкладка
  закрывается и приходит уведомление.

> Как это устроено: адрес читается из адресной строки браузера (UI Automation). Работает с
> Chrome, Edge, Brave, Opera, Vivaldi, Firefox. Реагирует только на **уже открытую** страницу —
> пока ты печатаешь адрес, вкладка не трогается. Это защита «от соблазна», а не от целенаправленного
> обхода: режим инкогнито/другой браузер такой метод тоже видит, но полностью герметичной
> блокировки без системного драйвера или правки hosts не бывает.

## Защита от закрытия и удаление

- **Не закрыть просто так.** Пока включён «сторож» (⚙ Настройки → «Тримати запущеним»), закрытие
  окна сворачивает в трей, а если приложение завершить (Диспетчер задач, сбой) — оно **само
  перезапускается**. Выход из трея требует PIN.
- **Не удалить, пока работает.** Windows держит запущенный `TimeApp.exe`, удалить файл нельзя;
  а если процесс убить — сторож поднимет его снова.
- **Удаление — только через бота.** Команда `/uninstall` от админа → бот показывает
  предупреждение и кнопку подтверждения → затем просит **PIN**. После этого приложение убирает
  автозапуск, удаляет свои данные и сам `.exe`, и выключается.

> Честно о пределе: полностью «неубиваемой» пользовательскую программу не сделать — админ Windows
> через Диспетчер задач («Завершить дерево процессов») может закрыть и приложение, и сторож. Для
> действительно жёсткой защиты нужна установка **системной службы** правами администратора — если
> нужно, могу добавить такой вариант.

## Несколько ПК

По твоему выбору сделана **локальная модель: один бот = один ПК** (без облака, всё крутится на самом ПК).
Чтобы контролировать **второй** компьютер:

1. Создай ещё одного бота у **@BotFather**, скопируй его токен.
2. На втором ПК запусти `TimeApp.exe`, открой **⚙ Настройки → Токен бота**, вставь новый токен, нажми «Применить».
3. Переключение между ПК = просто открываешь нужного бота в Telegram.

> Важно: один и тот же токен нельзя запускать на двух ПК сразу — Telegram разрешает
> только одного «слушателя». Если так сделать, второй покажет статус «токен занят на другом ПК»
> (программа при этом не падает и продолжает считать время локально). Для каждого ПК — свой бот.

## Сборка exe (билдер)

Нужен Python 3.10–3.12 с python.org (при установке отметь «Add to PATH»). Затем:

```
build\build.bat
```

Скрипт создаст виртуальное окружение, поставит зависимости, прогонит самопроверку, соберёт иконку
и выдаст **`dist\TimeApp.exe`** (один файл, без консоли).

## Автообновление через GitHub Releases — полная инструкция

Приложение умеет само проверять новую версию и обновляться. Источник — **GitHub Releases**.
Настраивается один раз.

### Шаг 1. Создай репозиторий на GitHub
1. Зарегистрируйся/войди на <https://github.com>.
2. Нажми **New repository**, придумай имя (например `timeapp`), можно **Private** или **Public** —
   для приватного скачивание всё равно работает, если релиз не помечен как приватный ассет
   (проще сделать репозиторий **Public**, тогда точно без токенов).
3. Запомни адрес вида `твой-логин/timeapp` — это и есть «репозиторий» для настроек.

### Шаг 2. Пропиши репозиторий в приложении
1. Открой **⚙ Настройки → Автообновление (GitHub-репозиторий)**.
2. Впиши `твой-логин/timeapp` (или полную ссылку — приложение само её сократит) и нажми
   «Проверить зараз». Строка версии внизу покажет текущую (например `Версія 1.0.0`).

### Шаг 3. Выложи новую версию
Когда собрал новый `TimeApp.exe`, который хочешь раздать как обновление:
1. **Подними номер версии** в `app/version.py` (`APP_VERSION = "1.0.1"`) и пересобери `build\build.bat`.
   Приложение сравнивает именно этот номер с тегом релиза, поэтому у новой сборки он должен быть больше.
2. На GitHub: вкладка **Releases → Draft a new release**.
3. **Tag** (тег) — поставь `v1.0.1` (буква `v` не обязательна, но привычна; главное — номер выше текущего).
4. **Title** — любой, например `1.0.1`. В описании можно кратко написать, что нового.
5. В блок **Attach binaries** перетащи файл — он должен называться **точно `TimeApp.exe`**
   (это имя приложение ищет среди файлов релиза).
6. Нажми **Publish release**.

### Как это работает у пользователя
- Приложение само проверяет релизы (первый раз вскоре после старта, затем каждые ~6 часов) и,
  найдя версию выше текущей, шлёт админам в бот уведомление «Доступно обновление».
- Обновить можно:
  - командой в боте **`/update`** — проверит, скачает и поставит (приложение перезапустится);
  - кнопкой **«Проверить зараз»** в ⚙ Настройках.
- Скачивается только ассет с github.com/`*.githubusercontent.com`, проверяется, что это настоящий
  `.exe` и разумного размера; сам работающий файл подменяется через маленький скрипт после выхода
  из приложения, потом оно стартует заново.

> Проверять новую версию приложение будет, только если репозиторий указан в настройках. Пустое
> поле = автообновление выключено.

## Как считается время

- **Активное время** — экран разблокирован и была мышь/клавиатура за последние 5 минут. По нему же считаются лимиты.
- **Время за экраном** — просто время с разблокированным экраном.
- Сон/гибернация и сами перерывы не засчитываются. День сбрасывается в полночь по локальному времени.

## Полезно знать

- Закрытие окна **не выключает** программу — она сворачивается в трей (у часов) и продолжает считать.
  Полный выход — правой кнопкой по иконке в трее → «Вийти / Quit».
- Блокировка на перерыв — это защита «от соблазна», не от злоумышленника: **Ctrl+Alt+Del** Windows
  перехватить нельзя, так что аварийный выход через диспетчер задач всегда остаётся.
- Данные и настройки: `%APPDATA%\TimeApp\data.json` (там же токен и список админов).
- При первом запуске SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае» (обычное дело для неподписанных exe).
- Токен бота — как пароль: кто знает токен, управляет ботом. Не публикуй его.
